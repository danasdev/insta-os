# Playbook de Instagram

Base técnica que todas as skills de conteúdo do plugin consultam. Cada arquivo em `references/` cobre uma parte; leia o que a tarefa pede antes de escrever ou desenhar.

| Tarefa | Leia |
|---|---|
| Decidir formato, frequência, horário; entender por que algo teve ou não alcance | `references/algoritmo.md` |
| Roteiro de reel, primeiros 3 segundos, edição, ritmo, fim | `references/ganchos-e-retencao.md` |
| Qualquer texto que precisa prender ou convencer (gancho, capa, legenda, DM) | `references/psicologia.md` |
| Carrossel e arte de feed (estrutura, tamanhos, tipografia, leitura no celular) | `references/carrossel-e-design.md` |

| Relatório, metas, diagnóstico | `references/metricas.md` |

## Como usar com rigor

1. **Separe fato de hipótese.** Os arquivos marcam o que a Meta/Adam Mosseri confirmou (**[oficial]**) e o que é medição de terceiros (**[medido]**, direcional). Nunca apresente um número [medido] ao usuário como regra do Instagram.
2. **Os dados da própria conta vencem os benchmarks.** Depois de 4–6 semanas de posts, use o histórico do Metricool como referência principal e os benchmarks só como contexto.
3. **Uma variável por teste.** Para aprender o que funciona (gancho, horário, formato), mude uma coisa por vez e compare blocos de 3 peças parecidas, não um post isolado.
4. **Checklist antes de entregar qualquer peça:** gancho nos primeiros 1–3s (ou na capa), uma ideia por tela, texto legível no celular, CTA único, motivo concreto para salvar ou enviar, legenda com palavras que o cliente buscaria, alt text.
