# Stories

Leia antes a skill `marca` e `playbook-instagram/references/stories.md`. Stories são onde a marca parece gente: menos acabamento, mais conversa, sempre com uma ação para o seguidor.

## Formato

- 1080×1920. Deixe 250px livres em cima e embaixo (barra do perfil e campo de resposta).
- 3–5 telas por sequência. A primeira prende (pergunta, bastidor, número), a última pede uma ação.
- Figurinhas são adicionadas no app pelo usuário: marque na arte onde vai cada uma (enquete, caixinha, link, contagem regressiva, menção) e diga o texto exato dela.

## Tipos de sequência

| Tipo | Telas | Ação |
|---|---|---|
| Bastidor | foto/vídeo real do processo (pedir ao usuário) + legenda curta na fonte de texto da marca sobre o fundo padrão | reação/emoji |
| Enquete de dor | "Sua loja vende mais pelo direct ou pelo site?" | enquete → quem votar vira conversa |
| Caixinha | "Qual processo da sua empresa ainda é na planilha?" | caixinha → respostas viram pauta de educativo |
| Post novo | print do post + "saiu case novo" | link/menção do post |
| Chamada | "Abrimos 2 vagas de projeto em <mês>" (só se for verdade) | link para direct/WhatsApp |
| Antes/depois | site antigo × novo de um case liberado | link para o case |

## Produção

- Artes no tipo **Design** com o design system (fundo ou textura da marca, uma frase na fonte de títulos, símbolo pequeno) ou HTML 1080×1920 exportado em PNG.
- Bastidores usam fotos do usuário: peça; não gere pessoas fictícias como se fossem a equipe.
- Entregue: as telas, o texto de cada figurinha, a ordem e o horário sugerido.

## Destaques fixos sugeridos

Cases · Produtos · Processo · Depoimentos · Contato. Capas dos destaques no padrão: fundo da marca, símbolo ou uma palavra em Michroma.

## Respostas

Para enquetes e caixinhas, prepare 2–3 respostas-modelo que puxem conversa (sem empurrar venda na primeira mensagem). Quem demonstrar interesse real pode virar lead: com permissão do usuário, registre no pipeline como origem "prospecção" com nota "veio dos stories".
